Comment ça marche

  1. Insère un tag NFC encodé dans la planche finie.
  2. Tape-le avec ton téléphone → cet écran s'ouvre.
  3. Choisis modèle · taille · couleur. Le n° de série est suggéré.
  4. Confirme → la planche est provisionnée, prête à expédier.

Le client n'aura plus qu'à taper le même tag pour l'enregistrer à son TK ID.
